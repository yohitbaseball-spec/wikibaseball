    站長的話

    歡迎來到架空棒球世界資料站。這裡不只是整理紀錄的地方，而是一個讓想像中的棒球世界能被完整保存的空間。無論是未來聯盟、虛構球員，或真實歷史的再詮釋，希望這個網站能成為你查資料、發想故事，甚至單純熱愛棒球時的一個據點。

    注意事項

    本內容為架空時代，因此絕大多數內容皆為虛構，包括球員姓名、一些球隊、選手成績 (利用遊戲進行模擬成績)、各隊強度 (包括高中、職業) 等等。球員姓名來源有三者：認識的朋友姓名 (取得版權)、名字產生器、自由創造名字，如果有與您重複的姓名，純為巧合。若你看到本篇內容後，想要置入自己的版面，請與此篇內容擁有者討論，我們很歡迎。請抱持著開心的心情觀看此篇維基百科！

    如果你想加入我們，把你自己投入到架空世界中，歡迎點擊：聯絡我們

    歷史和一些想說的話

    這個算是我的第一個「比較正式」的作品，架空世界主要是高中時打棒球自己和朋友所創造出來的，那時候就有想說要把這樣東西實體化。一開始是用 Google Docs 來做，大概做了 2 年多吧，發現 Google Docs 的限制性實在太多，開啟變超級久。後來就想說可以來做看看網站，一開始用 Google Sites，後來學了 HTML 就覺得更有趣了。大二寒假時決定移到 GitHub 來做，現在感覺還蠻順利的，就繼續做下去吧！
